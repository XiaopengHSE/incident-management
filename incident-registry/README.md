# 异常事件登记台

一个纯前端、零依赖（除测试外）的本地事件管理应用。所有数据保存在浏览器 localStorage 中，刷新不丢失，不连接任何外部系统。

## 快速开始

1. 直接在浏览器中打开 `index.html` 即可使用（推荐使用 Chrome / Edge）。
2. 无需构建、无需后端、无需配置。

## 功能说明

| 功能 | 说明 |
|------|------|
| 新增事件 | 填写标题、严重度、负责人和备注，点击保存 |
| 编辑事件 | 仅可对「进行中」的事件编辑信息 |
| 关闭事件 | 将事件状态标记为「已关闭」，关闭后不可再编辑 |
| 列表筛选 | 按严重度、状态、负责人、关键词实时筛选 |
| 超时提醒 | 创建超过 24 小时仍未关闭的事件会高亮提示 |
| 状态历史 | 每次创建、更新、关闭都会留下时间线记录 |
| 导出 CSV | 将当前列表（含筛选结果）导出为 CSV 文件 |
| 空状态 | 无数据时显示友好的引导提示 |
| 错误提示 | 表单校验失败或操作异常时弹出 Toast 提示 |

## 数据持久化

所有事件数据以 JSON 形式存储在浏览器 `localStorage` 的 `incident-registry-data` 键中。

**注意**：清除浏览器缓存或更换浏览器会导致数据丢失。如需备份，请使用「导出 CSV」功能。

## 本地测试

```bash
npm install   # 安装 Vitest
npm test      # 运行单元测试
```

## 项目结构

```
incident-registry/
├── index.html              # 主应用（单文件可运行）
├── app.js                  # 核心业务逻辑（数据层）
├── package.json            # 项目配置
├── README.md               # 使用说明
├── AGENT_LOG.md            # Agent 执行日志与验收文档
├── CHANGELOG.md            # 变更列表
└── test/
    └── incident-registry.test.js   # 单元测试
```

## 限制与假设

- 本应用仅面向单机本地使用，无多用户同步能力。
- 不使用真实客户数据，所有数据由用户手动输入。
- 不发送任何网络请求或消息通知。
